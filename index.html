C++ 教程

都是基础，我边学边记的。点卡片展开代码。
变量int / double / char 先定类型再起名，整数用 int，小数用 double。 展开 
int age = 13;
double pi = 3.14;
char c = 'A';
string name = "小腾";
数组array 一串同类型的数据，用下标访问，从 0 开始数。 展开 
int a[5] = {1, 2, 3, 4, 5};
a[0] = 99;          // 改第 1 个
cout << a[2];       // 第 3 个，是 3
字符串string 存文字用的，长度、拼接都有人写好。 展开 
string s = "hello";
cout << s.size();   // 长度，5
s += " world";      // 拼接
指针pointer 存地址的变量，* 取值，& 取址。 展开 
int x = 10;
int* p = &x;    // p 存 x 的地址
cout << *p;     // 取地址里的值，10
条件判断if / else 成立走 if，不成立走 else。 展开 
int score = 85;
if (score >= 60) {
    cout << "及格";
} else {
    cout << "不及格";
}
for 循环for 知道循环几次就用它。 展开 
for (int i = 0; i < 5; i++) {
    cout << i << " ";   // 0 1 2 3 4
}
while 循环while 条件成立就一直循环，注意别写成死循环。 展开 
int n = 0;
while (n < 5) {
    n++;
}
cout << n;   // 5
函数function 把一段逻辑包起来起个名，到处调用。 展开 
int add(int a, int b) {
    return a + b;
}
int sum = add(3, 4);   // 7
